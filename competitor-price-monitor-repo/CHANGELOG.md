# Changelog
## v1.5
- 默认不再为"表里没有链接"的格子去站内搜索(省页数、省时间)，记"无链接"，运行后汇报，由用户决定查哪些；需要时加 --search-missing。
- 运行结束生成《需手动查询清单.md》:程序没找到链接的格子，附官网首页、站内搜索网址和关键词(短/带内存)；也可单独运行 app/tools/manual_list.py 从最新一列生成。
- Media Expert: 页面写"Produkt chwilowo niedostępny"(无货)或卖家不是 Media Expert 自营(Marketplace 第三方)时记 unavailable，不再采用残留/第三方价格。
- 运行结束自动列出【链接疑似写错】和【价格异常待核对】(站间差>2倍，或与 RRP 相差>50%)。

## v1.4 (2026-11-07)
- 型号核对忽略三星型号代码(如 SM-X520)，平板 S10 FE 不再被误判成"链接商品与表不符"。
- 不计 Outlet/翻新/展示机/二手商品：搜索结果自动过滤，链接指向这类商品时重新搜索。
- 周四提前开跑：不带 --date 时，周四运行的结果自动记在周五的日期列(补漏同列)。
- 省页数：站内搜索确认没有该型号/内存、页面写明下架的格子记进 `competitor_status.json`，28 天内不再重复搜(结果写 `无此型号(已确认)` / `discontinued`)。
- 新增 `app/tools/mark.py`：把停售老款标成 `不查`。resume 把这些文字当作已完成。
